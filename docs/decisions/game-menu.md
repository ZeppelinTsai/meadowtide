# 資訊選單與 HUD 資訊分工

## 2026-08-27：背包擴充為資訊選單

`src/inventory-ui.ts` 與 `#inventoryOverlay` 沿用既有內部名稱，避免純命名
造成大範圍重構；玩家看見的名稱統一為「資訊選單」，與 Esc 開啟的
「暫停選單」（未來使用漢堡 icon）區分。Q／手把 Y 開關資訊選單，
Esc 在資訊選單開啟時只負責關閉它。資訊選單開啟後仍透過
`data-game-menu="open"` 與 `time-pause.ts` 暫停世界。

左右方向鍵依目前焦點決定語意：焦點在頁籤列時切換分頁；焦點進入內容網格後，
左右鍵優先在同一分頁的卡片間移動，不得因全域幾何導覽先跳回頁籤。LB／RB 與
中括號鍵保留為不受內容焦點影響的快速切頁鍵。

目前分頁為：

- **物品**：種子、收成、魚、牡蠣。
- 珍珠也列在物品分頁；所有物品縮圖統一依模型最長邊 1.05 世界單位正規化，避免魚等長型模型撐滿卡片。
- **素材**：木材、石材與礦物。
- **料理**：已持有的料理。
- **工具**：目前已入手的工具；只顯示文字。
- **關係**：NPC 印象；以 NPC id 查找資料，不依賴 `npcs` 陣列順序。

未來新增非即時資訊（更多 NPC 關係、任務、圖鑑、統計等）應優先新增至
這套資訊選單的分頁，不要重新堆到右上角 HUD。

## 右上角 HUD 的責任

`src/input-save.ts` 的 `updateHUD()` 只顯示需要遊玩時持續看見的即時環境
資訊：季節、日期、時段、天氣、時間。種子、收成、魚、料理與
NPC 印象不再重複顯示；物品數量由選單既有分頁呈現，NPC 印象由關係分頁呈現。

## 物品模型與背包圖示聯動

地圖資源、角色拿出的手持模型、「物品」分頁 3D 縮圖與右下快捷背包圖示，統一由
`src/inventory-system.ts` 的 `makeInventoryItemVisual(itemId)` 建立。新增或修改
可手持物品模型時，只修改這個工廠；資源物品必須沿用地圖的 `makeWoodPile()`、
`makeStonePile()`、`makeOreNode()` factory，`src/inventory-ui.ts` 不得另外指定另一套
同物品模型，避免世界中已換模型、背包仍顯示文字占位或舊造型。沒有專屬模型的
物品由共同工廠回傳方塊占位，直到正式模型補齊。

資訊背包與快捷背包共用同一個縮圖 renderer 與快取，禁止為快捷圖示再建立 WebGL
renderer。修改物品模型或圖示後，必須實際確認地圖、手持、資訊背包與快捷背包四處。

## 工具持有狀態與採集權限

「工具」是位於「關係」左邊的獨立分頁，顯示目前已入手的工具。工具使用可選取
卡片，卡片縮圖統一由 `src/tool-models.ts` 的 `makeToolModel()` 產生；模型不得在
`inventory-ui.ts` 另寫一份。選中卡片後，說明顯示在資訊面板共用 footer 的
`#inventoryDescription`，物品、素材、料理與關係卡也沿用同一說明出口。

工具目錄以 `src/tool-catalog.ts` 的 `TOOL_DEFINITIONS` 為單一資料源；持有狀態則以
`src/game-state.ts` 的 `inventory.tools`
與 `hasTool()` 為單一資料源；工具可能因加工、劇情或其他系統暫時消失，不得
再假設玩家永久持有。

目前雙用斧負責木材、地表石頭及兩座礦洞的礦石，鐮刀負責牧草。採集功能必須
同時在情境提示／目標建立、輸入執行入口及底層收成函式檢查工具；缺少工具時
不得顯示左下膠囊，也不得靠鍵盤、手把、滑鼠或其他呼叫路徑執行。舊存檔沒有
`inventory.tools` 時，為維持既有進度，讀檔會補成兩把工具皆已入手。

修改選單分頁或 HUD 後執行：

```bash
npm run build
```


## 物品與倉庫分頁

資訊選單的物品分類統一顯示背包內的種子、作物、魚貝、素材、礦物、珍珠與料理；數量為 0 的項目不建立卡片。舊「素材」與「料理」不再是獨立分頁。物品與倉庫的每頁容量必須依資訊面板寬度與視窗可用高度即時計算：欄數跟隨卡片最小寬度，排數至少一排、最多五排；視窗縮放時重算目前頁面。方向鍵維持卡片選擇，LT／RT 切換物件小分頁，LB／RB 專門切換大分頁。翻頁與 X 搬移提示必須呈現為可聚焦、可點擊的實際按鈕，不可只放靜態說明文字。物品與倉庫卡片的詳細選單也必須在「取消」前一項提供對應的「放入倉庫／放入背包」動作。

倉庫數量使用 `inventory.storage`，鍵值必須沿用物品系統的永久 item id，不得另建平行名稱。物品卡聚焦時按 X 每次搬一件：物品頁搬入倉庫，倉庫頁搬回背包。資訊選單關閉時必須同步關閉物品詳細選單並清除其焦點返回狀態，避免下次開啟重現舊選單。詳細選單開啟期間必須鎖住四方向鍵、Tab 與程式性焦點，背景頁籤、卡片和 footer 按鈕皆不可取得焦點。

工具卡片固定使用左右各半的兩欄 grid：左半只放模型預覽，右半只放工具名稱，避免圖片和文字共用同一小區域。

## 右下快捷物品

自由活動時十字鍵專屬快捷物品，不再作為角色移動備援；左搖桿仍負責移動。空手按任一十字鍵會拿出目前選定物品；持有時左／右切換同列物品、上切換下一個非空列、下收回。其他選單開啟時十字鍵仍交由共用 UI 導覽。快捷 HUD 與互動膠囊共用左下區域，有膠囊時自動堆疊在其上方；標題／開頭選單期間必須隱藏。中央物品與四個方向箭頭必須可用滑鼠點擊，卡片盡量維持正方形，不顯示詳細名稱，只保留圖示與右下數量，且只列出背包中數量大於 0 的物品。
