# 資訊選單與 HUD 資訊分工

## 2026-08-27：背包擴充為資訊選單

`src/inventory-ui.ts` 與 `#inventoryOverlay` 沿用既有內部名稱，避免純命名
造成大範圍重構；玩家看見的名稱統一為「資訊選單」，與 Esc 開啟的
「暫停選單」（未來使用漢堡 icon）區分。Q／手把 Y 開關資訊選單，
Esc 在資訊選單開啟時只負責關閉它。資訊選單開啟後仍透過
`data-game-menu="open"` 與 `time-pause.ts` 暫停世界。

目前分頁為：

- **物品**：種子、收成、魚、牡蠣。
- **素材**：木材、石材與礦物。
- **料理**：已持有的料理。
- **關係**：NPC 印象；以 NPC id 查找資料，不依賴 `npcs` 陣列順序。

未來新增非即時資訊（更多 NPC 關係、任務、圖鑑、統計等）應優先新增至
這套資訊選單的分頁，不要重新堆到右上角 HUD。

## 右上角 HUD 的責任

`src/input-save.ts` 的 `updateHUD()` 只顯示需要遊玩時持續看見的即時環境
資訊：季節、日期、時段、天氣、時間。種子、收成、魚、料理與
NPC 印象不再重複顯示；物品數量由選單既有分頁呈現，NPC 印象由關係分頁呈現。

修改選單分頁或 HUD 後執行：

```bash
npm run build
```
