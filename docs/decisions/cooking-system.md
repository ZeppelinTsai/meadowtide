# 料理選單與食譜解鎖

## 資料來源

src/game-state.ts 的 RECIPES 是食譜定義的唯一來源；食譜 id 寫入存檔後不得任意改名。inventory.learnedRecipes 只保存已解鎖的永久 recipe id，新遊戲與缺少欄位的舊存檔皆預設為空。居民教學、書架調查與劇情事件一律呼叫 learnRecipes()，不可用「擁有材料」推定玩家已學會食譜。

## 廚房流程

調查爐灶會開啟獨立的料理 UI。外觀只沿用資訊選單的奶油米色配色，不併入資訊選單分頁。UI 只建立已解鎖食譜的卡片；背包與倉庫合計材料不足時卡片必須 disabled，不能等玩家確認後才報錯。

選擇卡片後逐項顯示材料來源。預設優先扣背包，不足部分自動由倉庫補足；玩家可以將任一材料切換為優先倉庫。確認時由 cookRecipe() 再次驗證解鎖與總量，以防選單開啟後資料改變。扣料與產生成品必須是同一個同步操作。

## 序章

序章料理教學開始前，村長透過事件解鎖 grilledVeggie、seafoodSoup、mushroomSkewer。補給為三條魚、三份農作物與三朵蘑菇；玩家成功做出三道中的任意一道即可完成教學。序章之外的新遊戲初始不會任何料理。

## 存檔

Save v16 新增 inventory.mushrooms 與 inventory.learnedRecipes。讀檔會將蘑菇數量正規化為非負整數，並丟棄不存在於 RECIPES 的食譜 id；舊存檔安全預設為零朵蘑菇與零個已解鎖食譜。
