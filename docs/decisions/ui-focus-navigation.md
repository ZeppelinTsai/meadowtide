# UI 方向鍵與手把焦點導覽

## 硬要求

任何可互動 UI 無論何時都必須能只用鍵盤方向鍵或手把完成操作：

- 方向鍵與手把 D-pad／左搖桿可以移動到每個可操作項目。
- Enter／Space 與手把 A 可以啟動目前焦點。
- 返回、關閉與取消不能成為方向鍵到不了的孤島。
- 焦點必須有清楚可見的外框；disabled 或隱藏項目不得取得焦點。
- 子畫面切換後要把焦點放進新的可見畫面，不能留在已隱藏節點。
- 個別 UI 若要攔截方向鍵（例如教學卡片左右輪播），必須
  `preventDefault()`；共用導覽會尊重已處理的事件。

## 共用實作

`src/ui-focus-navigation.ts` 只在目前可見的 UI root 內，以元素畫面座標尋找
指定方向最接近的可聚焦元素。目前 root 包含標題畫面、暫停選單、資訊選單
與對話選項。新增 overlay 時應把 root 加進這個共同清單，不要在新模組另寫
一套上下左右索引。

`src/gamepad-input.ts` 在 UI root 可見時進入 UI 模式：

- 左搖桿／D-pad 送出 Arrow 方向事件，不再移動玩家。
- A 啟動目前焦點；尚未有焦點時先聚焦第一個項目。
- Start 仍對應 Esc；Y 仍開關資訊選單；LB/RB 保留資訊選單分頁切換。

## 2026-08-27 盤點

| UI | 原問題 | 現在 |
| --- | --- | --- |
| 標題主選單 | 只有初始 focus，方向鍵不移動 | 上下可走完所有選項 |
| 標題系統子頁 | 靜音與返回沒有方向導覽 | 上下互通 |
| 繼續遊戲 | slot 有初始 focus，但返回可能到不了 | autosave、9 格與返回上下互通 |
| 暫停主選單及子頁 | 各頁只靠滑鼠／原生 Tab | 共用方向導覽 |
| 資訊選單 | 左右鍵被 tab 切換攔截，無法到達關閉 | tab 與關閉可左右聚焦；LB/RB 仍可快速換頁 |
| 教學卡片 | 左右鍵已有輪播語意 | 保留輪播並阻止共用導覽重複處理 |

修改任何 UI 後先執行：

```bash
npm run build
```

並用鍵盤方向鍵及手把各走一次：進入畫面 → 所有選項 → 子畫面 →
返回／關閉。只驗證滑鼠點擊不算完成。
